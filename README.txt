# ShyLegend Portfolio

A free, responsive, single-page portfolio website.

## Customize before publishing
1. Open `index.html` in a text editor.
2. Replace `YOUR_DISCORD_USER_ID` in the Discord link with your Discord user ID.
3. Replace `YOUR_EMAIL@example.com` with an email address you use for client enquiries.
4. Replace the four `ADD YOUR WORK` placeholders with your real portfolio images or project previews. Do not present placeholder cards as completed client work.
5. Update the About text if you want.

## Free hosting
- GitHub Pages: create a public repository, upload `index.html`, then enable Pages in repository Settings.
- Netlify: use its manual deploy option and upload the folder.

No paid assets, frameworks or external libraries are required.
